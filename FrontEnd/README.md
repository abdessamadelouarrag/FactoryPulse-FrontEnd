# FactoryPulse — Frontend

La documentation du projet, les prérequis, les routes et la gestion des données sont disponibles dans le [README principal](../README.md).

Depuis ce dossier :

```bash
npm install
npm run dev
```

Au premier lancement, ouvrir `/machines` pour initialiser les données avant de consulter le dashboard.

Autres commandes : `npm run build`, `npm run preview` et `npm run lint`.
